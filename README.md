# My Tools 个人工具集合

收录我开发的 Windows 桌面小工具，每个工具放在独立的子文件夹中，
各自包含源代码、文档与使用说明。

## 工具列表

- [微信防封助手](wechat-anti-ban/)：配合微信 PC 版使用，将聊天文字一键转为纯文字 GIF 图片发送，
  让内容以图片形式传递，规避对文字的风控。
- [轻沙箱 LightSandbox](light-sandbox/)：比虚拟机更轻量的 Windows 应用隔离沙箱，基于独立账户
  实现软件多开、账号隔离，支持窗口化完整桌面，无需安装驱动。

## 目录说明

```
my-tools/
├── wechat-anti-ban/   微信防封助手（源码、文档、打包配置）
└── light-sandbox/     轻沙箱（源码、文档、配置模板、MIT 协议）
```

## 运行方式

进入对应工具的文件夹，按其 README 中的说明安装依赖并运行。
